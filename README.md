## Deep Learning Labs

A collection of hands-on labs exploring core concepts in deep learning, from foundational neural networks to more advanced architectures. Each lab focuses on a specific concept, combining theory with practical implementation.

### 📌 Overview

This repository contains coursework labs completed as part of a deep learning course. The labs progressively build understanding of:

- Neural network fundamentals
- Optimization techniques
- Convolutional Neural Networks
- Recurrent Neural Networks
- Model evaluation, tuning, and performance analysis
